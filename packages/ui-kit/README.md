# @three-pies/ui-kit

Общая основа интерфейсов витрины и будущей административной панели. Пакет не содержит товаров, цен, заказов, маршрутизации и сетевых запросов. Исходный TypeScript обрабатывает сборщик приложения; отдельной сборки пакета нет.

Галерея с интерактивными примерами: `http://127.0.0.1:5173/?view=ui-kit` после `npm run dev` из корня.

## Подключение

Добавьте приложение в `workspaces` корневого `package.json`, а в его зависимости — `"@three-pies/ui-kit": "*"` и совместимые версии React 19 / React DOM 19. Установите зависимости из корня. В точке входа:

```tsx
import "@three-pies/ui-kit/styles.css";
import { Button, TextField, Badge } from "@three-pies/ui-kit";

export function ProductForm() {
  return (
    <form>
      <TextField label="Название товара" name="name" required />
      <Badge tone="success">Доступен</Badge>
      <Button type="submit">Сохранить</Button>
    </form>
  );
}
```

Шрифт Golos Text подключается самим приложением локально через `@fontsource-variable/golos-text`. Без него используется Arial. Для обычного текста приложения задайте `font-family: var(--ui-font-body)`, для брендовых заголовков — `var(--ui-font-display)`. CSS пакета не сбрасывает глобальные стили приложения.

## Компоненты

| Компонент                     | Настройки и поведение                                                                                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Button`                      | `variant`: primary, secondary, ghost, danger; `size`: default, small; `busy`, `disabled`. По умолчанию `type="button"`; busy отключает повторное нажатие.     |
| `IconButton`                  | Обязательный `aria-label`, область нажатия 44 × 44 px.                                                                                                        |
| `Icon`                        | `name`, `size`, `className`; декоративный SVG скрыт от скринридера. Значение кнопки задаётся её текстом или aria-label.                                       |
| `Input`, `Select`, `Textarea` | Нативные props, состояния disabled, invalid, focus. Название задаёт вызывающее приложение через label или aria-label.                                         |
| `TextField`                   | `label`, `hint`, `error` плюс props input. Автоматически связывает подпись и описание, ошибка получает role=alert.                                            |
| `QuantityControl`             | Управляемый компонент: `value`, `onChange`, `name`. Допустимы целые 0–99, на границах кнопки отключены. Родитель хранит значение и валидирует внешние данные. |
| `Badge`, `Alert`              | `tone`: neutral, success, warning, danger. Alert объявляется как status, danger — alert.                                                                      |
| `Card`                        | Контейнер с фоном, границей и внутренними отступами; обычные HTML props.                                                                                      |
| `Table`                       | Обязательный `label`, children — thead/tbody. Прокручиваемая с клавиатуры область и скрытая подпись таблицы.                                                  |
| `Dialog`                      | `title`, `onClose`, children; опционально `wide`, `drawer`, `pageOnMobile`, `className`. Монтируется условно при открытии.                                    |

`Dialog` использует нативный `<dialog>`: изоляция фонового контента, цикл Tab/Shift+Tab, Escape, закрытие по фону и возврат фокуса. При открытии блокирует прокрутку, при размонтировании возвращает исходные стили и позицию, удаляет обработчики. На ширине до 600 px занимает доступную высоту экрана и учитывает `visualViewport`. Одновременно показывайте один диалог; вложенные диалоги не поддерживаются. Для восстановления фокуса исходная кнопка должна оставаться в DOM.

Для длинных форм включайте `pageOnMobile`: на ширине до 800 px и на сенсорном устройстве в альбомной ориентации с высотой до 500 px диалог становится отдельным экраном с прокруткой документа. Он выводится через portal непосредственно в body, остальное приложение временно скрывается из раскладки и дерева доступности. Поля не ограничены прокручиваемым контейнером, а клавиатура управляется браузером без пересчёта высоты по `visualViewport`. На компьютере сохраняется `showModal()`. Смена размера не размонтирует поля; при закрытии возвращается исходная прокрутка. Режим предполагает один открытый диалог и обычную прокрутку документа в приложении.

```tsx
{
  open && (
    <Dialog title="Подтверждение" onClose={() => setOpen(false)}>
      <p>Изменения будут сохранены.</p>
      <Button onClick={() => setOpen(false)}>Понятно</Button>
    </Dialog>
  );
}
```

## Токены и правила

`src/tokens.css` экспортирует цвета, типографику, интервалы 4/8/12/16/24/32/48 px, радиусы 4/8/12 px, высоту действия 44 px и тень диалога. Для использования только токенов: `import '@three-pies/ui-kit/tokens.css'`.

Основная палитра: молочный `#FFFCF7`, бордовый `#852C32`, золотистый `#B48C50`. Золото предназначено для декора; мелкий текст должен использовать тёмные семантические цвета. Статус обозначайте текстом вместе с цветом. Состояния focus/disabled/error/busy доступны в галерее. Анимации учитывают `prefers-reduced-motion`.

В admin переиспользуйте пакет и семантические токены, а собственную раскладку задавайте стилями приложения. CSS витрины `client/src/styles.css` для admin не нужен. Бизнес-компоненты вроде карточки товара, таблицы заказов с действиями или авторизации добавляются отдельно; UI-kit не заменяет серверную валидацию и контроль доступа.
