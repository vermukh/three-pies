# Три пирога — клиентский прототип

Адаптивная витрина осетинской пекарни на React, TypeScript и Vite. Desktop сохраняет исходное визуальное направление; мобильная раскладка работает от 320 px, с отдельной навигацией, нижней панелью корзины и полноэкранными диалогами.

«Три пирога» готовит только на доставку и самовывоз, без заведения для посещения. Адрес в интерфейсе обозначает точку самовывоза; тексты не должны приглашать гостей в кафе или зал.

## Запуск

```bash
# Из корня репозитория
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Галерея общих компонентов: http://127.0.0.1:5173/?view=ui-kit. Для production-сборки: `npm run build`; для её просмотра: `npm run preview --workspace=three-pies-client`.

Повторяемые браузерные проверки находятся в `tests/` в корне. Запуск и результаты описаны в [отчёте проверки](docs/verification.md). Проверяются desktop, мобильные и планшетные размеры, сценарии заказа, данные браузера, фокус и очистка обработчиков событий.

## Что работает

- Категории «Осетинские пироги», «Пахлава», «Напитки» и фильтры начинок.
- Карточка товара с составом и аллергенами.
- Добавление, удаление и изменение количества товаров; корзина сохраняется в localStorage.
- Конструктор набора из трёх пирогов; можно выбирать одинаковые начинки.
- Форма демонстрационного заказа с доставкой и самовывозом, проверкой обязательных полей и телефона.
- Информационные блоки пекарни, доставки, контактов и отзывы с действующего сайта.
- Диалоги с клавиатурной навигацией, Escape, удержанием фокуса и возвратом фокуса после закрытия.
- Мобильное меню разделов, нижняя панель быстрых действий, прокручиваемые категории/начинки и отзывы.
- На телефоне корзина прокручивает товары отдельно от кнопки оформления; форма сохраняет черновик при переходе к корзине и обратно.
- Общий UI-kit: токены, кнопки, поля, статусы, таблица, счётчик и диалог. [Документация пакета](../packages/ui-kit/README.md).

## Данные и ограничения

Всё работает в браузере. API, сервер, административная панель, платежи и отправка писем не реализованы. Контактные данные из формы никуда не передаются и не записываются в постоянное хранилище. Черновик хранится только в памяти страницы, очищается после демозаказа или перезагрузки. После оформления демозаказа корзина очищается.

`src/data.ts` — единственный источник моковых товаров, цен, состава и изображений. Ассортимент и цены пирогов/пахлавы опираются на доступные страницы прежнего сайта; напитки, полный состав, аллергены, диаметр и стоимость доставки 250 ₽ — демонстрационные данные. Перед публикацией их нужно сверить с пекарней. Отзывы перенесены с https://xn----8sbisb0bffeo.xn--p1acf/otzyvy/ с сохранением дат; рейтинги не выдуманы.

## Визуальное направление

Молочный фон, бордовый акцент, приглушённое золото; крупная антиква в заголовках, простой читаемый шрифт в интерфейсе. Декоративный геометрический узор — стилизация для прототипа, не документальная реконструкция национального орнамента.

Golos Text и Marck Script поставляются локально через пакеты Fontsource; запросов к Google Fonts при открытии страницы нет. Лицензии шрифтов включены в соответствующие npm-пакеты.

Изображения сгенерированы встроенным imagegen и служат иллюстрациями, а не фотографиями продукции пекарни. Все изображения находятся в `public/images` и не зависят от сторонних фотохостингов. Контактный лист каталога отображается через CSS background-position без дополнительных растровых преобразований.

Файлы:

- `public/images/hero-pies.png` — фотографическая иллюстрация трёх осетинских пирогов.
- `public/images/catalog.png` — единый контактный лист из девяти предметных иллюстраций.
- `docs/image-prompts.md` — точные промпты генерации.

## Структура

```text
src/

  components.tsx   — логотип, фото товара, адаптеры общего UI-kit
  data.ts          — моки, типы, восстановление корзины
  styles.css       — desktop-дизайн витрины
  mobile.css       — мобильная и планшетная раскладки
  UIKitPage.tsx    — интерактивная галерея компонентов
  ui-kit-page.css  — раскладка галереи
  main.tsx         — точка входа
public/
  images/          — локальные иллюстрации
  favicon.svg
```
